# Rediscover 教学引擎

## 阅读和揭示

每关是一篇配图教学文。课程目录和原课程链接默认打开阅读模式，读者可以切换到答题模式。两种模式共用正文、配图、失败方案、测量记录和推导。切换保留阅读位置和已提交的作答。具体内容和质量门槛见 [课程验收标准](lesson-acceptance.md)。

- 阅读模式按文章顺序展示完整的讲解。问题作为自然的思考停顿，证据在叙事需要时展开。读者可以顺序阅读到结论。
- 答题模式把题面与当下已经看到的内容放在一起。已展开的段落和作答留在同一页，随作答、主动查看推导或略过预测而继续。进度用序号显示。

| 步骤 | 读者动作与后续 |
| --- | --- |
| 阅读 | 点继续，展开下一步。 |
| 预测 | 提交预测或选择暂时想不出。记录原话或略过，再展开证据，把预测与观测并排呈现。 |
| 列式 | 提交后校验表达式。通过则展开下一步。部分正确或错误时停在本步，给一条合适的提示。读者可以主动查看推导。 |
| 解释 | 按本步判据给反馈。读者可补答或主动展开作者的解释。作者可以把已经展示的证据与待检验的解释放在同一屏。 |

答题会话按该会话的进度提供已开放内容。提前查看后续步骤的请求沿用揭示规则。答题动作成功后最多展开一个新步骤。AI 反馈使用当前已展开的信息和本步授权的提示。

## 课程和进度模型

正文用 Markdown，图片使用独立资源。课程配置由引擎读取，包含课程编号、版本、标题、按顺序排列的步骤。每一步有稳定编号、正文、配图和可选题目。题目定义类型、提示、判定条件与推进动作。证据步可以引用某个预测步的提交记录。以下是概念示例；现行 Markdown 步骤和图数据格式见 [作者说明](release.md#内容与判定)。

```yaml
id: B01
steps:
  - id: predict-sealed-mass
    content: predict-sealed-mass.md
    question:
      kind: prediction
      prompt: 如果把金属、空气与封闭容器一起称，前后质量会怎样？
    advance_on: [submitted, skipped]
  - id: sealed-evidence
    content: sealed-evidence.md
    compare_prediction_from: predict-sealed-mass
    advance_on: [continue]
```

保存课程版本、答题模式已开放步骤、每题尝试和推进方式。阅读证据门与答题进度分别存储；滚动位置按课程、版本、模式留在浏览器标签页内。刷新或在同一标签页切换后恢复位置，复核时可在答题模式查看原预测。通过作答、主动查看推导、主动要提示和阅读开门分别记账。同一提交动作重试只记录一次，提交旧步骤也只影响该题的记录。保存成功后再展示新步骤。

## 输入与判定

键盘和语音共用一个输入。语音先转写为可修改的文本或公式。读者确认后才提交；识别不了分组、数字或运算符时请求确认，保留原题状态。

- 预测保存原答案。推进取决于读者已经预测或主动略过。
- 列式题用确定性规则检查表达式与本题要求，区分等价式、单位与精度、部分完成和仅给数值等情形。可以把教学目标设为建立关系或计算结果。错误反馈对应具体错误。
- 解释题用作者给定的判据。AI 返回判据是否满足、具体反馈和需要澄清之处。当前证据不足以区分的合理解释可以保留，由后续证据推动。
- 引擎根据当前步骤和结果决定展开。提示与解释使用作者提供的内容。AI 负责输入理解与反馈表达，题目状态和证据由引擎管理。

A03 的列式判定接受 `800 ÷ (7.2 ÷ 360)` 与 `800 × 360 ÷ 7.2`。只写 `800 ÷ 7.2` 时指出这是每度对应的距离。只写 `40000` 时可以确认数值，请读者补计算关系。B01 的整体称量记录按原稿标注是教学模拟；应先收集预测，再展示实验，随后判断读者能否把固体与整体的记录结合起来。

## 验收与发布

- 先用 A03 核验连贯阅读和配图，再跑键盘及语音列式、等价式、部分正确和迁移题。用 B01 跑完预测、揭示、原话对照和修正解释。两篇通过同一套步骤规则运行。
- 每个课程编号都指向独立可读的完整正文，包含可加载的教学配图、失败方案及边界、可作答步骤、可验证的反馈和收束。发布清单以 [课程地图](curriculum-map.md) 为准。
- 发布检查校验 140 个编号、标题、发布路由、图片及相对引用、步骤揭示和题目判定配置。实际读者流程验证刷新恢复、重复提交、键盘、语音、预测略过、正确列式和错误反馈。
- 发布后以站点入口和课程 URL 验证可访问，按 A–N 逐系列核对上线数量，抽查手机和桌面阅读流程，报告版本、地址及可复查的结果。服务凭据由部署环境提供。
