# Rediscover 课程验收标准

适用范围为课程地图中的 A–N 共 140 课。先验收 A03 阅读样板及两种模式，再按相同标准改编和发布全量课程。

## 阅读模式

1. 从课程目录或普通课程链接进入时默认打开阅读模式。读者顺着同一篇文章可以直接读完正文、失败方案、证据、推导与结论。题目可以出现在叙事中，读者可以顺势思考和读下去。
2. 开头让首次读者能说出正在解决什么问题。正文建立对象与量的关系，交代一个真实的尝试或合理的初始设想，说明它遇到什么问题，再用新图或证据引出修正。结尾回答开头的问题，并说明可以如何复验。对历史实测、教学模拟与模型近似使用对应标注。
3. 段落之间交代过渡原因。读者看得出为什么需要下一张图、下一次测量或下一步计算。正文按阅读顺序自然滚动。需要先猜测再看证据的关键处可以在文中设置「看结果」等展开动作，正文余段和完整解答可直接读到。阅读动作独立于答题成绩。
4. 关闭答题交互后，用首次阅读者的视角从头走到结尾，仍能重述问题、失败的原因、修正方法和结论。章节和图注按叙事顺序出现，处于证据前的题面、材料与提示不提前替读者作出结论。

## 配图

- 每课至少有两幅承担不同教学作用的图，或一套包含两个以上有独立用途的分图。画出本课具体的对象、操作、证据、关系或前后对照。数据表可以辅助读数；解释空间或过程关系时用读者可以直接观察的图。
- 每幅图有对应的正文引用、图注与替代描述。关键图的对象、边、角、量、单位、方向和已有数据与正文一致；同一个量跨图沿用同一名字或符号。
- 小屏和桌面均能辨认关键标注。用文字或线型同时区分关键对象。发布检查验证图和图注能加载，逐课人工审阅确认每幅图解决了一个具体理解困难。

## 题面、推导与引导

- 每道题明确交代要回答的问题、已给数据、需要用到的条件、要交的形式及单位（适用时）。预测题说明要预测哪个实验结果；解释题说明要解释哪两条记录或判断哪两个模型。题面引用的图和信息在作答时已经可见。
- 关键推导的每一步说明输入从哪来、做了什么以及结果表示什么。量的定义、单位、参考零点、符号和误差在适用的地方写清。明确区分实测量、模型导出的量与最终结论。
- 从一个合理但失败或不足的做法出发，说明为什么会有人这样试、哪里露出问题、修正了什么。结尾用新数据、反例、预测或其他独立成果检查是否把该方法用对。
- 引导与当前困难对应。第一条提示指向缺失关系或需要复看的图，后续提示补充具体步骤。已知中间结果、典型误解、等价式和目标所需的单位各有可核对的反馈。解释题按作者写清的证据判据评阅。

## 答题模式

- 每课入口可直接切换到答题模式，题目按文章上下文出现。提交或略过预测后展示证据并保留原话；列式可以重试、查看提示或主动展开推导。未解锁图、图注、替代文字、数据和解答不随初始响应提供。
- 键盘与语音进入同一个可编辑输入框，语音确认后才提交。表达式等价、容差和单位由确定性规则校验；AI 在本步的题面、已开放证据与判据范围内解释反馈。
- 阅读和答题使用同一篇手稿的正文、图与推导。切换时保留本课进度与已提交作答。阅读或查看推导单独记录；新答题会话按其自身揭示规则开始。现有课程链接、会话恢复和重复提交的行为经过回归验证。

## A03 阅读样板

1. 画两站的实地观察。用木棍、地面和影子表示如何读出日光方向与竖直方向的夹角，标出站点与测量时刻。
2. 用失败对照图说明同一站换时刻影子也会变，进而说明同步观测和两站位置的条件。
3. 用行星剖面图画平行日光与各站竖直方向。在一站日光近似沿当地竖直方向的教学情形中，同时标出地面和球心的 7.2°。让读者看出等角来自什么几何关系，沿地表画同一经线的 800 千米弧段。
4. 画 800 千米对应 7.2°、待估周长对应 360°。先解释 7.2 除以 360 是 1/50 圈，再解释 800 除以 1/50 或求每度弧长为什么得到整圈 40,000 千米。答题时按步骤揭示推导。
5. 验证两种等价列式、部分计算、比例用反、单位和仅填写数值的情况。以新数据检验独立列式，并用第三站的观测检验模型。

## 发布验收

- A03 先经未参与撰写的审阅者试读，确认能指出图上两个 7.2°、说清 800 千米对应哪段及用新数据独立列式。样板检查覆盖阅读、答题、切换、预测与解答揭示、手机和桌面。真实学习者试读有条件时另记样本与结果。
- 分批提交每课的审阅清单，记录编号、阅读连贯性、图的教学用途、题面和引导、算式或证据复核。证据写到具体图、步骤或题目。
- 合并后以 140 个唯一编号为全集，逐课跑阅读与答题路径、图片、路由、题目和回复配置。A03、B01、A18、G04、N12 单独实走，另抽查各系列至少一课的文章与推导。在与正式入口一致的桌面和移动视口检查正文、公式和图，核验语音和已有会话。
- 发布记录包含最终版本、可访问地址、两种模式的全路线结果、独立审核与遗留事项。实际 dev 入口通过验证后登记上线。
