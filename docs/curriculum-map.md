# rediscover 课程与关卡地图

整理日期：2026-10-30。来源：项目发起人与助手关于 STEM 发现路线的讨论。

## 定位与状态

课程围绕大问题推进：提出猜想，作出预测，收集证据，建立或修改模型，再到新情境中检验。主线设计暂不受小学四年级接受能力限制；具体主持时再调整语言、提示和计算工具。

本地图确定 **10 条主线、104 个主线关卡，以及 3 组共 18 个共享工具关卡，总计 122 关**。编号用于课程定位与依赖引用，不规定每轮对话的问题顺序，也不表示已完成内容开发。

当前已有完整主持材料的是 [《火带走了什么？》](../lessons/fire/host.md)，覆盖 B01 的主要探究，并延伸到植物与人体物质账本。其余条目是待编写、核对和试跑的课程任务；本地图本身不是可直接交给学习者的主持剧本，也不改变项目暂缓网站开发的决定。

## 共同教学方式

- 一关是一个完整问题，可以包含多轮对话、实验和分支；通常依次经历猜想、预测、取证、解释与迁移检验。
- 主持时每轮只要求一个思考动作，依据回答推进；先预测再揭示证据，不预先提供答案菜单，不以说出术语判定完成。
- 完成成果可以是测量记录、实验方案、可运行装置、算法、证明或经过新数据检验的模型；数值正确不能代替解释。
- 实验发现、近似计算与数学证明分开处理；观察、条件推论、新知识、真实数据和教学模拟明确标注。
- 合理的替代解释接受同等检验；保留证据暂时不能区分的模型，不为预定结论补造实验结果。
- 顺序按概念依赖安排，穿插历史线索；教学重构不冒充真实历史发现过程。自由探索和跨线学习开放。

后续逐关开发须补齐：可交给主持人的材料、实验或模拟规则、证据及来源、分层提示、完成判据与迁移任务。已有剧本的主持细则见其正文，不在地图中重复展开。

## A 丈量宇宙：14 关

从地面到太阳系、恒星、星系。每把尺子都有适用范围，需要校准下一把尺子。陶哲轩与 3Blue1Brown 的两期“距离的阶梯”为叙事参考，采用作者勘误修正简化说法。

| 编号 | 关卡 | 任务与完成成果 |
| --- | --- | --- |
| A01 | 隔河的树 | 用已知基线与两个观测方向确定对岸位置；换观测点交叉验证距离。 |
| A02 | 地球的形状 | 比较球体、平面等模型对地影和不同纬度观测的预测，说明证据约束。 |
| A03 | 两根木棍量地球 | 根据两地距离与太阳高度差估计地球周长，列出几何条件与误差来源。 |
| A04 | 月食里的尺子 | 结合地影、月食时间与月球运动推断地月尺寸关系，处理影子收窄。 |
| A05 | 月球究竟多远 | 用月球尺度与视直径估计距离，利用另一组观测复核。 |
| A06 | 半个月亮量太阳 | 从半月几何估计日月距离比，展示小角度误差导致的大幅结果变化。 |
| A07 | 火星为什么倒着走 | 用地球与火星的相对运动重现逆行，预测下一段视运动。 |
| A08 | 拼出太阳系 | 用重复观测与行星周期重建相对轨道，区分形状比例与实际公里数。 |
| A09 | 给太阳系定标 | 比较不同地点的金星凌日观测，结合轨道比例估计天文单位。 |
| A10 | 木卫一的钟 | 用事件观测时差识别光程变化，结合太阳系尺度估计光速。 |
| A11 | 恒星会移动吗 | 用周年视差与地球轨道基线测距，识别分辨率限制及其他位置变化。 |
| A12 | 暗星一定更远吗 | 区分光度与视亮度，用已知距离恒星定标，估计适用类型恒星的距离。 |
| A13 | 会闪烁的灯塔 | 发现造父变星周期与光度关系，经独立定标后测量另一星系。 |
| A14 | 宇宙有多大 | 结合超新星等距离指标与红移，检验模型适用尺度，区分可观测宇宙与整个宇宙。 |

边界：月球处的地影直径不能直接当成地球直径；半月法适合展示误差敏感性；恒星视差依赖已校准的轨道尺度；宇宙尺度不能无限套用线性哈勃关系，也没有已知的整个宇宙大小。

参考：[第一期](https://www.3blue1brown.com/lessons/cosmic-distance-1/)、[第二期](https://www.youtube.com/watch?v=hFMaT9oRbs4)、[陶哲轩补充与勘误](https://terrytao.wordpress.com/2025/02/13/cosmic-distance-ladder-video-with-grant-sanderson-3blue1brown-commentary-and-corrections/)。

## B 物质的秘密：10 关

让模型先解释旧证据，再接受新实验挑战；后期连接内部结构与材料性质。

| 编号 | 关卡 | 任务与完成成果 |
| --- | --- | --- |
| B01 | 消失的东西去哪了 | 比较开放与封闭系统的质量收支，设计整体称量，检验消失与物质转移等解释。 |
| B02 | 固定的配方 | 从组成比例数据建立离散粒子解释，说明数据仍不能确定的内容。 |
| B03 | 气体的拼图 | 提出符合反应体积与原子守恒的粒子组合，区分原子、分子及粒子数密度假设。 |
| B04 | 数出看不见的粒子 | 比较布朗运动数据与模型预测，用统计关系估计粒子尺度或数量级。 |
| B05 | 原子还能再分吗 | 用阴极射线偏转等证据推断带电成分，修改不可分实心球模型。 |
| B06 | 射穿一张金箔 | 比较不同内部电荷分布的散射预测，解释少量大角度偏转。 |
| B07 | 原子为什么挑颜色 | 根据离散光谱建立能级模型，用能量差预测谱线。 |
| B08 | 电子的位置在哪里 | 比较经典轨道与量子概率描述，区分模型预测与单次观测。 |
| B09 | 原子为什么牵手 | 用简化相互作用能量模型寻找稳定间距，解释吸引、排斥与成键。 |
| B10 | 同样的原子，不同的材料 | 用组成与结构解释部分宏观性质，标明模型适用边界。 |

B03 特别约束：同温同压等体积气体含相同数目分子，是需要独立支持的假设，不能循环证明；一次氢氧反应不足以排除所有不同粒子数密度的解释。

| C10 | 不同外表，同一结构 | 对应循环旋转、模加法和相应复数乘法群，验证运算保持，探索子群与生成元。 |

| --- | --- | --- |

| D02 | 剪开之后，面积去哪了 | 剪拼推导平行四边形与三角形面积，解释等积条件。 |
| D03 | 放大两倍，增加多少 | 建立长度、面积和体积的缩放规律，用新形状验证。 |
| D04 | 围住一个圆 | 用内外接图形夹逼圆周率，解释细分如何收紧近似范围。 |

| D06 | 一层一层装满箱子 | 从单位立方体推导棱柱与圆柱体积，解释底面积与高度。 |
| D07 | 圆锥为什么是三分之一 | 从实验猜测进入分割或截面累积推理，解释同底同高体积关系。 |

D07 不以倒水三次代替证明。D08 的双圆锥尖端在球心，底面与外接圆柱两端重合；需明确几何条件和截面相等的理由。

## 内容开发与验收

地图的关卡名称和目标是后续内容清单，不是已实现网站或已验证教学效果的声明。当前优先继续试跑《火带走了什么？》，将实际学习者回答用于完善分支，再按本地图扩展主持材料。

每关至少具备以下可审查内容才记为“剧本就绪”：

1. 唯一的开场问题与学习者初始已知信息。
2. 竞争解释、可区分的预测，以及合理替代路径。
3. 证据卡、来源或模拟假设、测量不确定性与揭示条件。
4. 按回答选择的单问题追问、逐级提示和暂停恢复方式。
5. 与当前证据匹配的解释边界、常见误解与必要的证明。
6. 新情境中的迁移任务、完成判据，以及通往其他关卡的入口。

真实学习者完整试跑后，另记“已试跑”状态及待修问题。未来若恢复网站实现，沿用这些材料和判据；不能用章节介绍、按钮动画或一道选择题代替完整探究。
