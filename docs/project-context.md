# 项目背景与课程方向

## 学习目标

让学习者理解重要知识怎样由问题、相互竞争的解释和实验发展出来，而不只是记住最终结论。最初面向家庭中一个孩子使用；设计主线时暂不受小学四年级接受能力限制，具体主持时再调整语言和提示。

## 当前形式

项目曾尝试本地单用户网站和分步选择题。讨论中发现，选项及现象描述容易泄露答案，固定题序也难以接住合理的替代解释。目前改为先编写苏格拉底式主持剧本，用 ChatGPT 学习模式试跑；是否重新开发网站，待教学对话验证后决定。

已讨论的教学取舍包括：每轮只问一个问题，根据回答决定下一步；先预测再揭示证据；不给学习者预先列出答案菜单；合理的旧模型和替代解释需要接受检验，不能只因不符合现代结论就被宣布错误。

## 第一份剧本

《火带走了什么？》属于物质发现路线，围绕普通化学变化中的质量收支展开：

1. 燃烧后固体残留变轻，可能意味着什么。
2. 金属受热后变重，对候选解释有什么约束。
3. 怎样设计整体称量，检验物质转移与总质量关系。
4. 一棵树增长的质量来自哪里，怎样区分必要条件和材料来源。
5. 人和尿液、粪便一起称仍可能变轻，怎样建立完整的进出账本。

数值为明确标注的教学模拟。前半段重构早期化学研究者的知识处境，后半段转入现代案例。完整分支和揭示条件以 `lessons/fire/host.md` 为准。

## 后续课程方向

逐关规划见 [课程与关卡地图](curriculum-map.md)：10 条主线共 104 关，另有图与优化、反馈与控制、波与信号三组共 18 个共享工具关卡，总计 122 关。该地图确定课程任务与推荐依赖，尚不表示主持剧本已完成或已试跑。以下为主线方向概览：

| 主线 | 推进方向 |
| --- | --- |
| 距离的阶梯 | 地球大小、月球大小、地月距离，走向用视差测量恒星距离 |
| 物质的秘密 | 质量收支、固定组成、原子与分子假设，走向原子内部结构 |
| 数系的扩展 | 从计数和运算需求推动数系扩展，再进入对称、运算结构与群论入门 |
| 面积与体积 | 从面积测量逐步推进到圆锥、球等立体的体积 |
| 大炮怎样射得准 | 测量和预测运动，逐步引出弹道、力学与轨道问题 |
| 能量 | 从具体变化和做功问题，推进到能量转化与统一解释 |
| 计算机的历史 | 从计算需求、算法与机器，走向可编程计算机 |
| 信息 | 从记录、编码和传递信息的问题逐步展开 |
| 概率与证据 | 从不确定观察中形成判断，比较解释并更新判断 |
| 基因 | 从遗传现象提出模型，逐步探索遗传物质和机制 |

物质路线需要特别深入讨论：气体反应的体积比例能排除哪些模型，仍不能排除哪些模型；等温等压下等体积气体含相同粒子数为什么是值得提出的假设，以及还有哪些独立证据支持它。不能用这条假设本身循环证明它，也不能只用一次氢氧反应就声称排除了不同气体具有不同粒子数密度的所有解释。

## 接下来怎样推进

先用《火带走了什么？》试跑，记录主持人的实际回复和学习者回答。优先修正提前透露原因、复合问题、机械推进、忽略替代解释和虚构实验结果的问题。试跑记录可先保存在本地；纳入仓库前去掉孩子姓名、账号等个人信息。

该仓库目前收录课程材料与项目背景；早期网页原型尚未迁入。继续这个项目时，先从当前主持剧本和实际试跑结果出发。

## 学习模式参考

[OpenAI 官方学习模式介绍](https://openai.com/index/chatgpt-study-mode/)说明其采用苏格拉底式提问、提示和个性化反馈。学习模式提供通用教学方式，剧本补充具体证据、历史处境及揭示顺序；严格遵守单问题节奏和不剧透仍需实际验证。
