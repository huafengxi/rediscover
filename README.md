# rediscover

重走发现之路：通过苏格拉底式对话，沿着问题、猜想、实验和证据，重新探索科学、数学与计算机中的重要发现。

当前先打磨可以交给 ChatGPT 主持的教学剧本。网站暂缓开发，先验证对话本身是否有挑战、是否能根据学习者的回答推进。

## 开始体验

第一份剧本是 [《火带走了什么？》](lessons/fire/host.md)，从燃烧后固体变轻出发，逐步检验质量变化的解释，再迁移到树木生长和人体质量变化。

在 ChatGPT 中启用学习模式（Study and learn），上传完整的 `lessons/fire/host.md`，然后发送：

> 请使用学习模式，按照附件主持《火带走了什么？》。每次只问一个问题，等待我回答后再推进。不提前透露结论，不展示后续证据，不提供选择题。先让我提出解释和预测，再揭示对应实验结果。现在从指定开场开始。

完整主持稿包含后续证据和主持判断，适合由家长准备。学习者从对话开场进入。
